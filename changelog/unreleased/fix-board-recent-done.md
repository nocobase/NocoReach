## Tasks board: Done keeps the last week

- The board's Done column shows tasks still being watched after going live and tasks that finished in the last 7 days, as Linear and Jira do, so it no longer grows without end. A task's age counts from when it finished, not from its last edit, so a comment does not bring an old task back.
- When older finished tasks are left out, the column ends with one line ("12 finished earlier, in the list →") that opens the Done list. The column's count is the cards it shows; the Done scope, Results, Insights and By Agent are unchanged.
