## Tasks: every closed task can be reopened and resumes where it was closed; every list column sorts

- Every closed task offers Reopen, on its page and in the list's row menu. A task closed before it started goes back to waiting to start; one stopped halfway goes back to the step where it was closed, keeping its results, approvals and history. A review returns as it was, an Agent step the closing stopped waits for Start this step again, and a change the closing withdrew goes back to the Agent step that made it, which opens a new pull request when started again. A merged or live change never goes back.
- The closed card says where Reopen takes the task, and Activity records the reopen with that step. The text saying a task stopped halfway could not continue is gone.
- Every column of the Tasks list sorts on every scope, as the Keywords tables do, and the sort is kept in the address. Closed lists the latest closed first.
- A task page's Activity names no longer wait for its Performance numbers: reading the daily data gives way to other requests.
