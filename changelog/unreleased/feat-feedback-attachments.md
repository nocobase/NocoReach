## Tasks: documents with a message or change request

- A started task's message box, which is the change-request box while a step waits for review, and the Request changes box on an article's review card and reading page take the files a new task takes: PNG, JPEG, WebP and GIF images, and Word (.docx), Excel (.xlsx), PDF, CSV, Markdown and plain text files, 20 MB each and ten a message. Documents show as chips with their name and a button to remove them, and the paperclip is named Add attachment. A file of another type is refused with the types a message accepts; the article body, the cover and Edit directly still take images only.
- The draft keeps documents as well as images. Activity lists a sent message's documents, each previewing or downloading as a new task's attachments do.
- The server checks each document's type, content and size on upload, and the files a message links: the sender's own uploads, as many as a new task's attachments.
- A run that reads the message or change request receives its documents through the task materials mount (`documents.json`), listed with the request they came with, so a redo knows which feedback each file belongs to. The demo Agent reads them before it writes.
- The demo Agent quotes several change requests in one sentence with the language's own separator, without a full stop after each.
