## Analysis rules: four opportunity categories, and Skills in the daily analysis

- Analysis rules groups its rules by the Opportunities category they find, in five tabs: Trending now (open by default), New content, Competitor gaps, Content optimization and Current situation. The 28 growth rules are named by their Opportunities type, with their source's icon before the name and its name in the last line; each tab says in one sentence what it answers and links to that category in Opportunities. The other 33 rules and custom rules are under Current situation, still under their sources, as they only update the current situation; Add rule says so. Frequent community terms is the new name of the community topic rule, and Rank drop no longer mentions entering the top 10.
- A rule that ran in the last analysis of the scheme version in view and found nothing shows 0 instead of Not run yet.
- Each analysis scheme can pick up to five Skills, in a Skills block below the rules or from a Skill's detail on Skills (Use this Skill to find opportunities every day). The default scheme of every project gets content-strategy, competitors and ai-seo once; a removal sticks, a copied scheme keeps its Skills and a deleted Skill leaves every scheme. Add Skill is searchable and estimates the input tokens each Skill adds a month.
- Every day each selected Skill gets one call on the Daily analysis model, with its SKILL.md body and up to about 10k tokens of the day's saved data, and proposes up to three opportunities citing keywords, pages or questions. The server keeps a candidate only when everything it cites is in the data and computes its growth and category with the rules' formulas; kept candidates join the daily report and the opportunity says which Skill found it. A Skill that fails says why on its own row and does not stop the analysis. No new paid lookups.
- The finding Skill goes to the agent with the step's Skills when the opportunity is handed off. Skills shows Daily analysis in Used in, filters by it, and the detail says what the Skill found in the last 30 days, linking to Opportunities filtered by that Skill, where the category counts also follow that filter.
- The demo's Acme default scheme uses the three default Skills with their last run, an approval workflow opportunity found by content-strategy and three others found by the default Skills, the rules' last counts, and a user-written Skill, comparison-pages.
- The default scheme's name is shown in the reader's language on Analysis rules and Skills; it is still stored under its Chinese name, and names people give their schemes stay as written.
