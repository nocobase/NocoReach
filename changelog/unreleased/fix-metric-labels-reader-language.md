## Audit › Performance: metric names in the reader's language

- A check's metrics are named by their Lighthouse key in the interface language, in the result drawer, its ⓘ and the brief handed to the Agent. Server response showed its Chinese name in every language, for new and earlier checks alike; earlier checks now read correctly without being checked again.
- Server response shows only its time ("490 ms"), as the other metrics do, instead of Lighthouse's English sentence "Root document took 490 ms".
