## Previews: open with the demo's data

- A first installation with `APP_SAMPLE_DATA=true`, as a Studio preview is, builds the demo's two projects, their collected data, tasks, knowledge and five accounts, without Demo Mode, so they can be changed like ordinary data. The accounts sign in with `<username>123`.
- Existing installations and Demo Mode deployments are unaffected. These projects' requests stay in process; starting new Agent work on them needs a real Runner.
