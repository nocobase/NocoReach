## Content workshop: card styles made with AI, and cards drawn by a Skill

- Card style adds My styles. Make a new style with AI writes a whole Xiaohongshu card style from a sentence describing the look, optionally with a reference image, using the model on the Editing and suggestions row. It previews the cover, the longest and shortest cards and the closing page with the project's own text, and checks that every card fits (the longest text is also checked at the 110-character limit), the number of colors, the logo and the fonts. What else to change and Generate again revise it; Save to My styles is offered once every card fits. Saved styles are picked, renamed and deleted like the built-in ones; a style the brand kit uses cannot be deleted. A model that cannot read images is named beside the reference image, and without a model the dialog points to the model settings.
- A style written by a model is cleaned on the server and in the browser before it is drawn: only layout elements and attributes are kept, CSS that loads anything or names a font other than the bundled font variables is dropped, and every rule is limited to its own card. The card page builds a style's layouts element by element without parsing markup, runs under a Content-Security-Policy that allows only its own scripts, and the browser previews draw it in sandboxed frames. The fonts are open-licensed families that fall back to the system's; NocoReach ships no font files.
- Draw with a Skill is the other way to make the cards: the brand kit names a Skill that draws them instead of a style. The picker lists guizang-social-card-skill and baoyu-xhs-images, each linked to its repository and added by the user under Skills (NocoReach does not include either), and any added Skill whose description says it makes card images. The run gets the Skill, the brand color, the closing page and the logo, and is refused if the Skill is no longer added. Cards a Skill drew have no Edit directly; the review says to use Request changes.
- The demo's main project has one saved style, Forest editorial.
