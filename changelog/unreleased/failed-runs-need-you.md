## Tasks: a failed Agent run waits for you

- A task whose Agent step failed, or that was stopped or withdrawn by closing and waits to be started again, now counts as Needs you, as a failed merge does: in Tasks › Waiting for me and its count, the Tasks badge, the Insights waiting strip, the status tag, the board's Needs you column, the By Agent view and what the online agent says of the task. The Current step keeps its red Agent run failed or amber Waiting for you to start it again label; Try again or Start this step again puts the task back in progress.
- The server's task status, its notifications and the online agent now read the same state rule as the pages, so an article that could not be published or exported also counts as Needs you in the list and the badge, as it already did on the server.
- A run that fails again after its card was moved by hand returns to Needs you. A failed run sends no message yet.
