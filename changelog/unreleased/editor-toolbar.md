## Tasks: a formatting toolbar in Markdown boxes, and no hint lines beside them

- Markdown boxes (an article body in Edit directly and on the article page, a document under review, a step finished by hand) have a toolbar over the text, as dev.to's editor does: bold, italic, link, numbered list, bulleted list, heading, quote and code, plus Add image where the box takes images. Each button's tooltip names it with its shortcut (⌘B, ⌘I, ⌘K). Heading goes ## → ### → none; quote and the lists prefix the selected lines and come off when pressed again; code wraps a selection in a line, or makes several lines a fenced block. The text keeps the cursor, and ⌘Z undoes a button like typing.
- Edit directly no longer shows "Paste or drop images into the body · PNG, JPG, WebP or GIF, up to 20 MB each" beside Cancel and Save, and Activity's message box no longer shows a hint line beside Add image, which is now the right-side chat composer's attach button. Images can still be pasted or dropped; the limits show only as an error when a file breaks them.
