## Hand-off briefs and page text: punctuation in the interface language

- What pages hand to the Agent (Audit › Performance, Site audit, Search performance, Keywords, Competitors, Trends, community and GitHub lists, Insights) and the lists, details and labels on those pages separate their parts with the interface language's marks. An English brief read "Scores: Performance 62，Accessibility 94" and "- https://x.com/p（Mobile，Nov 2）：Performance 62，LCP 3.8 s"; it now reads "Performance 62, Accessibility 94" and "(Mobile, Nov 2): Performance 62, LCP 3.8 s". Chinese text is unchanged.
- Japanese lists use "、" everywhere; some lists used ", " before.
- Settings › Network: deleting a profile asks "Delete network profile “Name”?" and a test reads "Received a response from the target: … · HTTP 200 · 120 ms. This only checks …" without Chinese marks; Audit › Performance's DataForSEO prompt ends with a full stop in its own language.
- A failed Lighthouse check is followed by its original title in parentheses only when its name reads differently, so English no longer repeats "Reduce unused JavaScript (Reduce unused JavaScript)". Competitors › Activity briefs put a space before each link.
