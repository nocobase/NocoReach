## Content workshop: Xiaohongshu cards

- What to make offers Xiaohongshu notes: the agent turns an article or topic into 6–18 card images of 1080×1440 with the note's title and body, following the new Xiaohongshu cards playbook and its `xhs-cards` Skill. It renders the cards on its own computer from a template drawn in the project's card style and uploads them with the new `task file` command; the images are kept with the result and readable by whoever can read the task. The template sizes each card's text so it fills the card, with body text of at least 36 px; it marks points only when a card has two or more, and avoids a last line of one or two characters.
- The review card shows the cards as a gallery, each with the source sections it comes from; a card over 110 characters, or one the agent found overflowing, is framed in yellow. NocoReach's checks cover the source sections used, the cover heading within 20 characters, the number of cards, at most 3 colors (counted from the images) and each card's length, and show the overflow check when there is one.
- Edit directly on review changes the text of each card and of the note, card by card with a live preview and a warning when the text does not fit. Saving draws every card again in the browser with the same style and saves it as a new version, without the agent; edited cards are labelled and Activity names them. Changing the layout or the number of cards still goes through Request changes.
- A finished set offers Download N images as one ZIP, Copy title and Copy body. Records name the number of cards.
- Brand and templates adds Card style, with four built-in styles (Editorial, Memo, Dark tech and Checklist) previewed with the latest set's own cards, and Brand basics: a logo (the website's icon unless one is uploaded), the brand color and a fixed closing page. A new style applies to tasks started after it.
- The demo's main project adds two Xiaohongshu tasks with rendered cards, one done and one waiting for review.
