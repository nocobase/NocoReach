## Analyses: each analysis's evidence stored once

- An earlier analysis keeps its opportunities, verdicts and the changes they cite; its whole evidence is archived for 180 days, where the online agent reads a past day. Plans keep no copy, and tasks keep only the changes they cite. Existing data is cut down once at start.
- Handing off a change or a data page no longer computes the analysis again when the latest analysis holds it, which also called the model for custom rules.
