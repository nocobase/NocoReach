## Insights: a change a Skill found is the same change the next day

- A change a Skill finds in the daily analysis is identified by what its growth rests on: the site's page, or the keyword or question with the most searches. When the Skill cites other keywords for it the next day, it is still the same change, so Ignore, Watching and a hand-off to an Agent hold instead of starting over.
- Changes a Skill found before the update are identified anew once, at the first analysis after it: an ignored one can show again, and a watched one reads as Back to normal and is watched again from its first day if the analysis still watches it.
