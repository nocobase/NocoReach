## Backlinks: broken pages to win links back, and a monthly check that feeds the daily analysis

- Link profile has a Broken pages tab: the site's pages that no longer open (4xx or 5xx) while other sites still link to them, most linked first, with their status code and link counts. The Broken backlinks tile opens it. On your own site, selected pages go to the agent as one Technical fix task that redirects each address to the closest live page or restores it, so its links count again. The online agent can read and propose this lookup too.
