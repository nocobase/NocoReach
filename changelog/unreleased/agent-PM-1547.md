## Keywords: every DataForSEO market, and several ways to find keywords at once

- Find keywords picks the market as a country, searched by name among every country DataForSEO has keyword data for, and one of the languages it has there, the country's main language first. Simplified Chinese is among them (Singapore · Simplified Chinese); pairs DataForSEO does not support cannot be picked, and the server refuses them.
- AI suggestions changes its market from the same list, and a keyword's overview opens in any of these markets.
- Contains the term, Related searches and Similar topics can be chosen together. Each is one DataForSEO query (about $0.024 for up to 100 keywords), counted beside Query with the most the search may cost before anything is looked up; the results are merged into one list without duplicates, and a Found by column names every method that found each keyword.
