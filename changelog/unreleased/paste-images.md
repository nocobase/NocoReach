## Tasks: images in messages, change requests and Edit directly

- Activity's message box takes images on a started task: paste, drop or Add image (PNG, JPG, WebP or GIF, up to 20 MB each, ten a message). They are numbered Image 1, Image 2 in the order added, so the text can refer to them; removing one renumbers the rest. A sent message or change request shows its images under the text, each opening large.
- The Agent receives the images with the message, numbered the same way. It treats an image that points at a problem as reference only, and places an image in the article only when the text asks for it.
- Edit directly takes an image pasted or dropped into an article body at the cursor, as GitHub's editor does: `![Uploading name…]()` while it uploads, then the image, shown in the preview at once.
- In review, a new image shows in the preview with a note on which message it came from (never published), and Changes lists the images added, replaced or removed.
- On approval, the images an article shows are uploaded to the NocoBase CMS file library first and the article is published with their CMS addresses; images it does not show are not uploaded. Other target kinds do not take task images yet: approval says so.
