## Backlinks: link profiles, the link gap, outreach tasks and the online agent

- Search & market has a Backlinks page, after OpenSEO's backlinks page. Its Link profile tab looks up a domain (your site by default, subdomains included) or one page address: authority, backlinks, referring domains and pages, spam score and broken backlinks, and, for a site, how its backlinks and referring domains grew and how many links it gained and lost each month over the last year.
- The Backlinks, Referring domains and Top pages tabs are each a separate lookup, run only when asked for. Each reads its first 100 rows, which the page sorts, filters (words to include or exclude, Dofollow only) and exports as CSV without another charge. Hide spam, on by default, hides rows with a spam score of 40 or more.
- The Link gap tab compares our domain with up to three competitors, by default those listed on Competitors: the sites that link to a competitor but not to us, strongest first and those linking to several competitors on top, with how many such sites each competitor has.
- Sites picked on Link gap, or among a competitor's referring domains, can be handed to the agent as one task with the new Link building playbook: the agent checks each site and drafts how to approach it and a message, and sends nothing. A brief from a competitor's referring domains says they were not checked against our links.
- The online agent has a backlinks tool: it reads the saved lookups of any view, the link gap included, for free. It never runs a lookup itself: when none is saved it proposes one, shown in the conversation as a card with the estimated cost and this month's spending, and the lookup runs only when the user clicks Look up there, under their permission to run lookups and the project's DataForSEO budget.
- Lookups run on the project's DataForSEO connection and monthly budget like Domain lookup: the same lookup within 30 days opens the saved result (across month boundaries too), Check again asks anew, and a refusal over the DataForSEO account's balance says so. Recent lookups reopen a target with whichever tabs were looked up, however many lookups of other kinds the project has run since. A site without history (a new site, a subdomain) still gets its overview, with the trend left out and why. Domain lookup's results have View backlinks, which opens the same domain on Backlinks.
- The demo projects have their backlinks and link gap looked up, including a spam row, nofollow links and sites shared by two competitors. The demo world now answers backlink lookups as the real API does: history as the items of one result, ranks on the 0–100 scale every lookup asks for, and no lost links when only live ones are asked for.
