## Tasks: change the playbook after the start

- A started task can start again with another playbook while no Agent run is queued or running and nothing has been published: Change playbook on a stopped step's card, or on the playbook's line under Given to the agent at the start, brings the start card back with the original playbook preselected. Start begins the new playbook's first step; the brief, pages, attachments, owner, Agent and messages stay, and the earlier playbook's results, change requests, versions and partial results do not carry over, even for steps with the same key. Activity records "changed the playbook: A → B" and keeps naming earlier lines and versions by the earlier playbook's steps. An automatic title follows the new playbook; a title changed by hand stays.
- A step stopped by a person reads as stopped, not as a failure: a grey "You stopped this step" card that says who stopped it and when, with Start this step again, Change playbook, Switch Agent and Message the Agent. Stops are recorded in Activity, show as Waiting for you to start it again in the task lists and are left out of "failed N times in a row". The note to ask a developer to check the site appears only for playbooks that change the site.
