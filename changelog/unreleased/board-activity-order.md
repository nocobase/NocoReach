## Tasks: the board and the list run by the latest activity

- Every board column lists its tasks newest activity first, and a card's time is that of the last line in the task's Activity. Something Activity does not show, such as the hourly effect check writing a reading, no longer changes it. The list's Updated column shows and sorts by the same time, and Done lists it newest first. The time in that column now sits on the same line as the other cells.
- Each effect reading is a line in Activity, from the System, in the words of the status chip: "recorded the day 7 result: not enough data", "recorded the day 28 result: Clicks ↑ 26%".
- Cards are no longer reordered by hand: dragging moves a card to another column only, and the card menu no longer has Move up and Move down. A move to the card's own column records nothing.
- By Agent's waiting lane and the Insights strip of tasks waiting for you list the latest activity first; the daily analysis reads the tasks active in the last 30 days by the same time.
