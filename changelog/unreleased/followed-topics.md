## Followed topics: one list in Memory that every source searches

- Project knowledge › Memory has a Followed topics item below Competitors: up to 10 topics in your market, edited as tags in the Memory dialog and read by the AI with the rest of Memory. A line says which sources search them, with the DataForSEO cost per topic a month (about $0.62).
- Reddit, Hacker News, YouTube, Google Trends, GitHub hot topics and AI questions search the followed topics besides the product name. Reddit and YouTube search each topic once a week, Hacker News reads the past week's top stories (free), and GitHub falls back to a text search when a topic is not a GitHub topic.
- Reddit, Hacker News and YouTube split what they find into Topic discussions and Mentions of us. Each item is marked with its topic, and each source page has one line that says what it searches, with Edit in Memory.
- The lists that Trends, AI questions and GitHub hot topics kept before are merged into the shared list once, with repeats counted once and nothing dropped. A project with more than 10 topics is asked to trim the list, and until then the sources search the first 10.
- The first Memory draft fills the topics from the website, competitors and keyword groups. The weekly check suggests rising topics not followed yet, with the evidence, under the AI's update suggestions.
