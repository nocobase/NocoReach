## Tasks: open every version of an article and restore an earlier one

- Activity is the article's version history. A version edited by hand reads "Edited the article draft, version 4 · View", and opens in the same dialog as the Agent's versions. In that dialog, Changes compares the version with the one before it, for the Agent's versions as well.
- While the article waits for review, the dialog of an earlier version has "Restore this version". Restoring creates the next version with the chosen one's whole article: every language, title, description, body, image, slug and status. Nothing is deleted, no Agent runs, and the task stays in review. Activity reads "Restored version 5 as version 11 · View", and the review card's version line reads "Version 11 · restored from version 5".
- Restore is offered to whoever may use Edit directly. It is not offered after approval or publishing, on a closed task, or for a version from an earlier round, such as the primary language before it was approved for translation. The server checks the same rules (`restoreArticleVersion`), as well as the task's revision and the version under review.
- A restored version records whether a person wrote the text it restores (`restoredFrom.byHand`, read with `writtenByHand`), so the Agent's next run can treat it as a hand edit.
