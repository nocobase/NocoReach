## Paid checks: a click asks again or says it did not

- Audit › Performance: Check runs a new Lighthouse check every time. The same page and device checked within 10 minutes returns that check, and the form says so with View that result instead of opening it as new. The ⓘ states the cost per check (about $0.005).
- DataForSEO runs that a click did not start come back marked `reused`, and a forced refresh still returns the same query's run from the last 10 minutes, so a double click is not billed twice.
- AI search › competitor gaps: Check again (about $0.3) asks again; before, it returned the saved check for 30 days.
- Trends: Update now, saving the settings and adding a keyword ask again; the weekly check still reuses runs from the last 6 days, and a reused run keeps its own date instead of the click's.
- Competitors › domain lookup: a saved lookup from the last 30 days says so above the figures, with Check again, as Keywords does. Keywords and AI search tell a saved result from the `reused` mark instead of comparing clocks.
- Rank tracking and Reddit keep their 6-day reuse; Update now and Search now now say when results were reused instead of counting them as checked or reporting no new posts. The rank tip names the Update now button.
