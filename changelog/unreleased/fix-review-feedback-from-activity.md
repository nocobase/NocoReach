## Task page: feedback written in Activity during a review makes the Agent revise

- While a version waits for your review, Activity's message box is where changes are asked for. Its hint says the Agent revises the work once you send it, the button reads Send feedback, and sending returns the step to the Agent at once. The message is recorded once, as the change request.
- Request changes on the page change, article, document and translation review cards, and on the article's reading page, no longer opens a box of its own: it takes you to Activity's message box. Text written there stays when the step moves on, and an edit not yet saved is kept under Earlier task drafts.
- At other steps a message stays a note, and its hint says who reads it: the run that starts the task, the step's next run, or, while publishing or waiting for the change to go live, no run. Members who cannot review the task still leave notes.
