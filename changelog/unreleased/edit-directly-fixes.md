## Tasks: Edit directly full screen, Markdown shortcuts, no page check phrase, narrower revisions

- Edit directly has Edit full screen beside the language tabs: the article page opens still editing, on the same language and with the unsaved changes, and Back to task returns to the editor as it was left. Moving between the task page and its article page no longer asks about leaving drafts behind; leaving the task still does.
- Markdown boxes (an article body, a document under review, a step finished by hand) take ⌘B, ⌘I and ⌘K (Ctrl on Windows and Linux) for bold, italic and a link, as GitHub's editor does: the selection is wrapped, or the marks are written with the cursor between them, and the same key takes them off again. ⌘Z undoes them like typing.
- Edit directly no longer shows Page check phrase. After publishing, the page check keeps the Agent's phrase while the approved text still shows it and the article did not before; otherwise it picks a new sentence of 8-200 characters from the paragraphs the version adds or rewrites, primary language first, or a new title. A hand edit that removed the Agent's phrase is now checked instead of waiting for a person to confirm it live.
- An article run after a change request receives the version the request is about, whole (`article.previous`, with its number and whether a person edited it), instead of only the source article. Its rules say to revise that version, change only what the request asks and keep every other sentence as it is, keep a person's wording, and, when a request to go back to an earlier version could mean more than one version, return the version unchanged and ask in the summary rather than guess.
