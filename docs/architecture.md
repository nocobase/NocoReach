# 技术结构与运行边界

## 当前实现

- NocoBase 3.0.0-alpha.7 本地新环境，独立于旧系统；版本为当前实现记录，不宣称是最新发行版。
- React/TypeScript Portal 承载业务页面和导航；应用自有路由集中定义。
- 自定义连接插件适配 Google 和 DataForSEO；复用旧连接器的报表、映射与研究解析，保留许可证，不复制旧密钥。
- PostgreSQL 保存项目业务数据、同步任务、分区、研究记录与候选。
- 认证布局内短期内存缓存避免切页重复整屏加载；退出布局销毁，不关闭鉴权。

## 数据链路

浏览器授权/操作 → 服务端项目和权限检查 → 凭据服务/连接器 → 第三方 API → 持久同步或研究记录 → 分析聚合 → 页面与任务。

同步先暂存，按项目、资源、来源、日期和粒度事务更新数据及游标。研究使用幂等请求键、预算预留与缓存；未知结果需人工核对，不自动补发。

## 安全与运行限制

- 密钥和令牌由服务端加密变量服务保管，不入仓库，不回显到前端或日志。
- 当前仅既有项目和管理员试运行。开放市场用户前需项目/角色/记录级后端授权与隔离验收。
- 本地数据库依赖 Docker，服务依赖本地运行进程及网络条件；关闭电脑后不能持续采集。
- 发布成功不代表业务验收通过。CLI 会话、数据库和外部授权均可能独立失效。
- 本仓库尚无源码与部署自动化；不得将文档仓库描述为可一键部署的系统。

## 后续源码入库前检查

选定唯一开发源目录，保留第三方许可证；审查依赖与安装说明；只加入必要应用代码、模型、迁移和测试。排除数据库备份、真实数据、会话、密钥、生成产物和运行日志。后续在同一 PR 更新代码、规格与测试；在完成迁入前，文档提交中标明对应部署和本地测试文件。
