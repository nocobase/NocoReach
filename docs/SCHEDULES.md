# 定时任务的调度时区

在“设置 → 定时任务”打开任务的“编辑时间”，选择每日执行时间和调度时区，然后保存。可以搜索 `Asia/Shanghai`、`America/New_York` 等 IANA 时区，也可以选择 `UTC`。当前设置页管理每日分析任务；内部采集和检查计时器不在这里配置。

调度时区决定每日时间的含义。例如每日 09:00 在 UTC 是 09:00Z，在上海是 01:00Z。保存只调整该任务，立即重新计算下次执行时间；刷新或服务重启后仍保留。暂停任务保存后仍暂停。已有任务在主动保存前继续沿用原配置及默认时区。

任务详情分别显示执行计划、调度时区和下次执行时间。执行记录等时间戳按页面标注的浏览器时区显示；展示时区不会改变调度时区。

夏令时沿用现有调度规则：纽约春季不存在的 02:30 顺延到 03:30；秋季重复的 01:30 在持续运行时通常只取第一次。停机恢复可能先补发旧计划，再触发第二次，因此不保证全局只产生一个调度事件。每日分析按任务当地日期跳过当天已分析成功的项目；失败后的重试规则保持原样。

每日分析当天漏跑后，在计划时刻过去至少 15 分钟时补偿。修改配置不会补跑修改前的计划时刻；跨日判断也采用任务时区。
