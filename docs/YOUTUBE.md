# YouTube 公开内容研究

YouTube 通过项目已接入的 DataForSEO 读取，接法与“Reddit 讨论”相同。不需要部署采集器，也不需要 YouTube API Key 或 yt-dlp。费用计入 DataForSEO 每月预算。

## 设置

1. 在“数据接入 → DataForSEO（关键词、竞品、AI 搜索）”接入 DataForSEO。未接入时，YouTube 面板会提示先完成这一步。
2. 打开“数据接入 → YouTube”，点击“填写搜索词”，每行填写一个搜索词，最多 5 个，每个 2–80 字符。第一次打开时会预填项目名称。
3. 可选：在同一对话框填写要单独跟踪的视频链接，最多 5 个，例如自己发布的视频。支持 youtube.com/watch、youtu.be、Shorts、Live 链接和视频 ID，分享参数会移除。
4. 保存后立即读取一次，并默认开启“每天自动读取”。之后可以在面板中关闭每天自动读取，或点击“立即读取”。

## 每次读取的内容

- 每个搜索词搜索一次 YouTube（DataForSEO YouTube Organic，美国英语市场），读取搜索结果第一页，最多 20 个视频，按 YouTube 的相关度排序。记录标题、简介、频道、发布日期、时长和播放量。广告、频道和播放列表不计入。
- 新找到的视频再读一次视频详情（DataForSEO YouTube Video Info），补上点赞数和评论数。已保存过的视频不会重复读取详情；单独跟踪的视频每次读取都会读取详情。
- 一次读取最多读取 20 个视频的详情，其余的排到下一次读取。第一次读取通常会找到较多历史视频，详情费用比之后几天高。
- 播放、点赞、评论是读取当时的数值，不是历史曲线。缺失的数值保留上次的有效值，0 是有效值。
- 某个搜索词超时或没有返回结果时，其他搜索词照常更新，面板会写明是哪个词；所有搜索词都失败时，这次读取记为失败，已有数据不变，并在 15 分钟、1 小时、3 小时、6 小时后重试。

### 关于“按上传日期排序”

YouTube 在 2026 年 1 月调整搜索筛选，移除了“按上传日期排序”。2026-11-02 在 YouTube 搜索页核对，带 `sp=CAI%253D` 参数的结果仍按相关度排列，没有按上传时间排序，因此读取时不传这个参数，只按相关度搜索。较新的视频可能不在第一页，需要用更具体的搜索词或单独跟踪的视频链接补充。

## 费用

按 DataForSEO 2026-11-02 的列表价：每次搜索约 $0.002，每读取一个视频的详情约 $0.006。立即读取会重新请求；10 分钟内重复点击会复用上一次结果，不重复收费。每天自动读取在 20 小时内复用已有结果。

面板按当前设置估算每月费用，并显示 DataForSEO 本月已用和每月预算：

- 搜索：搜索词数 × 30 × $0.002
- 单独跟踪的视频：视频数 × 30 × $0.006
- 新视频的详情：已有 7 天以上记录时按实际发现新视频的速度估算，否则按每个搜索词每天 1 个新视频估算，每个 $0.006

关闭每天自动读取后，面板显示每次读取的大约费用。

本月预算用完时，YouTube 本月暂停读取，下月 1 日自动恢复；在 DataForSEO 面板调高每月预算后，下一次每天自动读取会恢复。已保存的视频照常查看。

## 查看数据

已保存的视频在“社区 → YouTube”查看：按所选时间段统计这段时间发布的视频（没有发布日期的按首次保存日期计入），可按播放、点赞、评论排序。页面顶部一行说明搜索词、是否每天自动读取和更新时间。读取失败的原因在“数据接入 → 数据健康”中查看。

## 保存、清理和断开

- 视频按项目和视频 ID 长期保存；新发现的追加，重复的按视频 ID 合并更新，首次发现时间不变。修改搜索词、关闭每天自动读取、断开接入都不会删除已保存的视频。
- “清理已获取数据”经两次确认后删除本项目保存的全部 YouTube 视频（含早期采集器读取的字幕），并关闭每天自动读取；搜索词保留。读取进行中不能清理。
- “断开”移除搜索词和单独跟踪的视频，停止每天读取；已保存的视频仍可在数据页查看。

## 从采集器读取方式迁移

2026-11-02 之前，YouTube 通过 NocoReach Collector 调用 yt-dlp 读取；10 月 29 日起 YouTube 的机器人校验使这种方式持续失败。升级后：

- 原有的搜索词（最多 5 个）和单独跟踪的视频保留，每天自动读取默认开启；接入 DataForSEO 后，下一次每天读取即开始。
- 采集器保存的视频保留，之后按视频 ID 合并更新；早期读取的字幕保留，新的读取不读取字幕。
- 采集器读取时的失败记录清空。YouTube 面板不再显示采集器连接。项目中已保存的 YouTube 采集器连接（`nrVariables` 中的 `NOREACH_COLLECTOR_youtube_<项目 ID>`）不再读取，可以保留，也可以由部署管理员删除。
- 网络出口改为 DataForSEO 的出口，与关键词、排名、Trends、Reddit、AI 搜索共用，在“设置 → 网络”中统一管理。

## 不包含的内容

不包含字幕、频道所有者 Analytics、观看时长、受众、收入、评论全文，也不下载音频或视频。不读取浏览器 Cookie 或登录账号。

## 数据保留和第三方使用条件

“长期保存”是本应用的存储行为，不授予任何平台访问或无限期保存权利。只在有权获取、使用和保存相关数据的部署中启用；管理员负责确定适用授权、刷新和删除要求，以及备份副本的保留期。应用不会静默删除本地记录。

数据来自 DataForSEO 的 YouTube SERP API，使用时需遵守 [DataForSEO 服务条款](https://dataforseo.com/terms-of-service)。[YouTube 服务条款](https://www.youtube.com/static?template=terms) 对内容的使用另有限制。必须删除的本地数据，由管理员通过“清理已获取数据”处理，并按部署规则清理备份。

## 模拟环境与验证

模拟环境由模拟插件按 DataForSEO 的响应格式返回合成视频，不连接 DataForSEO 或 YouTube；演示数据同样使用合成视频。读取流程、费用记录、预算暂停和存储以本地测试验证，不使用真实账号或付费服务。

维护者需要在目标部署中用少量搜索词点击一次“立即读取”，确认找到的视频和实际费用。
