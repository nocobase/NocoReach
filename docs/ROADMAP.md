## 现状

主流程已经全部做出来，在用户本机的 NocoBase（127.0.0.1:13004）上每天运行：

接数据 → 每日分析找出变化并给结论 → 机会 → 交给 Agent → 本机 Agent 修改仓库、开 PR → 你看效果并发布 → 核实上线 → 第 7、28 天看效果，必要时撤回

2026-10-07 起能在一台全新的 NocoBase 上照 [安装说明](INSTALL.md) 装起来（已从头验证），代码在 GitHub 的 main 分支。

## 待你决定

① 每日分析给 AI 看哪些数据：现在规则先扫全部数据源、最多挑 40 条变化给 AI。可选：没有变化的数据源也给 AI 一段简短汇总；查询和页面样本从各 20 个加大；把知识库摘要交给 AI。（2026-10-04 起待定）

② Agent 和在线 AI 怎么共享资料：方案见 [agent-context-sharing-proposal](research/agent-context-sharing-proposal.md)，有 3 个问题。

③ AI 搜索要不要做“提到竞品、没提到你”的问题：要先花钱实测 DataForSEO 的排除条件。

④ 每日分析的失败处理：
- 服务在计划时间没运行，恢复后当天补跑一次；
- 确定没计费的失败（连不上、服务商明确拒绝）按 5 分钟、15 分钟、1 小时重试，最多 3 次；
- 可能已计费的失败（超时、中途断开）不重试；
- 最终失败在洞察页顶部显示原因和“重新分析”；
- 当天成功后不再自动运行。

⑤ 交给 Agent 的两个细节：要不要让 Agent 起草社区回复；交给 Agent 的弹窗里要不要能补一句话。

## 已知限制

- 只有管理员能用，没有多人权限；每个项目的本机 Agent 要单独连接。
- 绑定 NocoBase 3.0.0-alpha.7。
- Google 正式数据只同步到 3 天前，之后几天的初步数据只画在图上、不进分析。
- 本机 Agent 首版只支持 Claude Code，只改博客与文档的 Markdown/MDX；GitHub App 授权未做，暂用本机 gh 登录。
- 网站内容在 Git 和 CMS 两边都能改时，以 Git 为准（见 SPEC 第 13 节）。
- 前端打包后有几个较大的文件，首次打开稍慢。
