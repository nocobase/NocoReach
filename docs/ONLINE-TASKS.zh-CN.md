# 在在线助手中查看和启动任务

在线助手可以查询任务并委派 Runner Agent 执行。实际任务仍由 Runner 完成。

可以这样提问：

- “列出我负责的所有任务，包括其他项目。”
- “列出我创建的任务。”
- “哪些任务现在可以交给 Runner 执行？”
- “查看这个任务为什么不能执行。”
- “把这个任务交给指定的 Runner，然后启动。”
- “重试这个任务当前的 Agent 步骤。”

助手按当前登录用户的权限查询。“我的任务”默认指你负责的任务，也可以指定你创建、参与或有权限查看的任务。较长的列表按页读取；归档任务默认不显示，可明确要求包含归档任务。

点击回复中的任务标题会在当前应用、当前浏览器标签页打开对应项目的任务页；其他链接保持原有的新标签页打开方式。即使浏览器之前选中的是其他项目，也会按链接中的项目加载。权限不足或项目编号无效时不会回退到其他项目。

启动前需要可用的 Runner、相应执行权限及满足流程要求的配置；涉及仓库修改的任务还需要仓库配置。助手可以按你的要求选择 Runner，再启动或重试任务。正在执行、已关闭或需要人工处理的任务，不会被自动推进。任务提交或排队不代表执行完成，请在任务页查看进度和结果。

人工审核、发布确认仍需在任务页完成。任务或网页中的文字不会被视为你授权启动任务的指令。
