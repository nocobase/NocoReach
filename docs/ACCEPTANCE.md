## 第二轮退出标准

- [ ] 新项目无需开发者搬数据，完成授权、资源确认、首次同步和一次自动更新。
- [ ] 来源、项目、日期和数据口径可追溯；不同项目不能读写彼此数据。
- [ ] 重跑幂等，断网/授权失效/重启可恢复，凭据和错误日志无泄漏。
- [ ] 官网内容清单可以采集并增量更新。
- [ ] 长周期回补与对比正确说明缺失和覆盖。
- [ ] 第三方研究结果→详情→候选→内容机会真实跑通；收费与未知结果恢复经核验。
- [ ] 页面、路由、空态、失败态、窄屏及核心编辑流程统一回归。

## 第三轮退出标准

- [ ] AI 基于页面与项目证据给出具体建议，明确事实/假设/缺失。
- [ ] 用户确认并编辑后保存行动，AI 不越权，不自动发布或付费采集。
- [ ] 调用失败不丢编辑内容；复盘不虚构效果或因果。

新增验收记录应包含日期、功能、测试方式、结果、证据位置、尚未覆盖范围。脱敏前不上传截图、运行日志或实际业务数据。
