# 手动创建任务

在任务列表页点击「新建任务」，填写当前项目的标题和任务说明，即可创建待处理任务。创建不会调用模型、运行 Agent、发布内容或生成 PR；后续在任务详情中选择工作方式并启动。

说明输入框支持粘贴图片或视频文件，也可以通过上传按钮选择文件，或将文件拖入说明区域。每个任务最多 5 个附件，每个文件最多 20 MiB，支持 PNG、JPEG、GIF、WebP、MP4 和 WebM。上传中或上传失败时不能提交；失败的文件可以移除后重新上传。文件名按普通文本显示，详情中的视频带播放控件且不会自动播放。

只有剪贴板提供实际文件时才能粘贴媒体；复制视频链接只会粘贴文字，不会自动下载链接。操作系统和浏览器未提供视频文件时，请使用文件选择或拖放。上传的未保存文件限保留 24 小时，离开表单时会尝试清理；已经关联任务的文件不会被草稿清理删除。媒体需要登录并具有 NocoReach 成员权限，草稿文件仅当前上传者的原会话可关联。

切换项目或登录会话会使当前草稿失效，请退出表单后重新创建。网络失败时使用「重试创建」会重试相同内容和请求键，避免重复任务；明确的输入或权限错误允许修改草稿。离开未保存表单会提示确认。

## nocoreach CLI

使用已经登录当前应用的 `nocoreach` CLI：

```sh
nocoreach task create --help
nocoreach task create --project 1 --title "检查落地页" --description "检查并记录问题" --request-id <UUID> --json
nocoreach task create --project 1 --title "检查落地页" --description-file brief.md --request-id <UUID> --json
```

`--description-file` 读取完整的多行文字文件。创建结果的 `result.data` 包含字符串任务 ID、任务编号、项目和 `source: "manual"`。每次新任务生成新的 UUID；重试原请求时保留 UUID 和全部输入。相同请求返回同一任务，复用 UUID 但改变内容会返回冲突。CLI 和页面调用同一个创建接口。

当前 CLI 创建命令支持文字和多行说明，尚未提供经过验证的附件上传流程；上传媒体请使用页面。
