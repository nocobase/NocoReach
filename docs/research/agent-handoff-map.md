# 各页面“交给 Agent”一览（2026-10-03 夜里做好，等你看）

原则：在哪个页面看到值得做的事，就在哪里勾选，再点底部浮出条里的“交给 Agent”（2026-10-08 起：勾选任何一行，窗口底部浮出一条，显示数量、这个列表别的批量操作和“交给 Agent”，随滚动一直在；同一页几个列表一起勾也合成一个任务；详情抽屉的按钮在抽屉右上角）。勾选的内容合成**一个任务**：
- 页面上的数据（排名、曝光、点击、搜索量、竞品页面等）写进任务说明；
- 默认选好合适的做法，弹窗里可以改；
- 能对上“网站内容”里的页面时，自动关联这一页；
- 确认后立即开始，并直接打开任务页。
