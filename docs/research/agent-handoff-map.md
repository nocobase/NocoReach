# 各页面“交给 Agent”一览（2026-10-03 夜里做好，等你看）

原则：在哪个页面看到值得做的事，就在哪里勾选、点“交给 Agent”。选中的内容合成**一个任务**：
- 页面上的数据（排名、曝光、点击、搜索量、竞品页面等）写进任务说明；
- 默认选好合适的做法，弹窗里可以改；
- 能对上“网站内容”里的页面时，自动关联这一页；
- 确认后立即开始，并直接打开任务页。
