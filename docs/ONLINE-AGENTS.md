# 使用在线 Agent

升级后可同时使用两类 Agent：

- **在线 Agent**：直接使用服务器配置的模型服务，适合项目问答、调研、内容大纲和回复草稿，不需要个人 Runner。
- **Runner Agent**：运行在执行机上，用于代码仓库、修改文件、PR 等工作。

管理员先在“AI 团队 → 模型服务”配置可用的聊天模型，然后打开“在线 Agent”。内置的 Online Agent 使用默认模型；也可以添加 Agent，指定模型和工作说明。

在“项目 AI”选择默认任务 Agent，或在任务中单独选择。需要操作代码仓库的任务必须选择 Runner。系统不会在两种执行方式之间自动切换。

顶部聊天按钮提供“在线 Agent”和“Runner Agent”选项。在线对话可以查看历史、继续提问、停止执行和展开阅读。数据源连接向导中的问题会带上对应项目，打开在线聊天草稿；点击发送后才执行。

在线工具可以读取项目和任务资料、读取公开网页、保存候选草稿。成果仍需按原有流程人工审核，Agent 不会直接发布、发送消息或批准自己的结果。模型用量显示在每次在线执行记录中，暂不计入插件的总用量页面。

旧流程中的在线步骤可手动重试。升级前已中断的运行不会自动恢复，已有结果与历史记录仍保留。旧插件中被停用的 Agent 需要重新选择新 Agent；其对话历史仍通过原插件的历史入口查看。

停用 Agent 会阻止新任务，并停止正在执行的工作。网络故障后请使用“重试”：系统会复用同一请求，避免重复创建任务。执行超时或服务中断后，检查保留的记录，再决定是否重新执行。
