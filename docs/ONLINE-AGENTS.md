# 使用在线 Agent

在线 Agent 用于对话，可以读取项目资料和公开网页，回答问题、讨论调研思路或在对话中起草内容，不需要个人 Runner。任务中的分析、草稿、代码修改和 PR 操作统一交给 Runner Agent 执行。

管理员先在“AI 团队 → 模型”配置可用的聊天模型，再打开“Agent → 在线 Agent”标签。内置的 Online Agent 使用默认模型；也可以添加 Agent，指定模型和工作说明。

顶部聊天按钮提供“在线 Agent”和“Runner Agent”选项。在线对话支持查看历史、继续提问、停止生成和展开阅读。数据源连接向导中的问题会带上对应项目，打开在线聊天草稿；点击发送后才调用模型。

在线 Agent 只有读取项目资料和公开网页的工具，不会创建或执行任务、保存任务成果、操作仓库、发布内容、发送消息或批准结果。对话里的草稿供你参考，不会进入任务审核流程。每轮对话会显示工具调用及模型用量，在线用量暂不计入插件的总用量页面。

关闭聊天面板后，已发送的回答仍会继续生成，可以重新打开查看。完成后页面会停止轮询；切回页面或点击“刷新”可查看其他窗口中的更新。“停止”会中止当前回答并保留已生成的内容。

网络故障后可以重试发送，系统会复用同一请求，避免重复生成。认证失败、配额不足、请求限流或网络问题会显示对应提示。超时或服务中断后的回答不会自动重跑；检查已有内容后再决定是否重新提问。未完成的回答会保留在历史中，但不会作为后续回答的上下文。

停用 Agent 会阻止新消息，并中止正在生成的回答。会话仅对创建它的用户可见，历史记录会保留。
