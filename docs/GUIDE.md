# NocoReach 使用手册

English: [User guide](en/GUIDE.md)

更新：2026-10-07。安装见 [安装与升级](INSTALL.md)，每个页面的详细规则见 [产品设计](../SPEC.md)。

## NocoReach 是什么

NocoReach 帮内容放在 Git 仓库里的团队（重点是开源产品）回答两个问题：现在最值得改哪几个页面？改完以后效果怎么样？

它每天读你的网站和产品数据，由在线 AI 找出值得做的事；你点“交给 Agent”，你自己电脑上的 AI 编程工具（Claude Code）按团队的做法修改网站仓库、提交 PR；你在 NocoReach 里看过效果再发布，之后系统对比改动前后的数据。

## 基本概念

| 概念 | 是什么 |
| --- | --- |
| 项目 | 一个产品和它的官网。可以有多个，在页头切换 |
| 数据源 | 接进来的一种数据：Google Analytics、Search Console、网站内容、GitHub、论坛、下载量、DataForSEO 等 |
| 变化 | 程序按规则从数据里找出的一条变化、缺口或问题，每条都带数字和时间范围 |
| 洞察 | 每天更新的首页：关键指标、最新变化、今天值得做的事、等你处理的事 |
| 机会 | 在线 AI 认为值得做的事，附依据。交给 Agent 后变成任务 |
| 任务 | 一件具体的工作：用哪种做法、谁执行、做到哪一步 |
| 做法 | 一类工作怎么做，由几个步骤组成，比如 Agent 分析、Agent 修改、你审核。自带 11 种，可以改，也可以让 AI 起草新的 |
| Agent | 干活的 AI。在线 AI 负责每天分析、提出机会；本机 Agent 在你的电脑上执行任务 |
| Skills | 某类事情怎么做的说明（如文档写作规范），执行任务时交给 Agent |
| 项目知识 | AI 对这个项目的了解：记忆（品牌、产品、受众、用词、禁区等结论）和知识库（参考资料） |

## 界面语言

界面有简体中文和英文：点右上角头像 → 语言。选择存在你自己的账号里，不影响别人。看不到“语言”时，请管理员在 NocoBase 系统设置里启用两种语言。

AI 写的内容（每日分析、机会、任务文档、项目记忆）按项目设的语言写：建项目时选，以后在“项目知识”最上面的“AI 写的内容用的语言”里改。改了以后，新写的内容用新语言，之前写好的不变。

## 第一次使用

1. **建项目**：第一次打开时填产品名称、官网，再选 AI 写的内容用中文还是英文。以后在页头点项目名可以添加更多项目。
2. **接入在线 AI**：AI 团队 → Agent → 添加 → 接入在线 AI。
3. **接数据**：设置 → 数据接入。可以先点“发现数据”，输入官网地址，AI 会找出能接的数据源，你勾选确认后再接。建议至少接 Search Console、Google Analytics、网站内容；源码在 GitHub 的再接 GitHub。
4. **补项目知识**：建项目后 AI 会读官网，写出初版记忆。到“项目知识”看一遍、改一改，再把竞品资料、客户反馈等放进知识库。
5. **连电脑**：AI 团队 → Agent → 添加 → 连接一台电脑，在装了 Claude Code 的电脑上运行给出的命令。然后在数据接入里填“网站源码”仓库，Agent 就改这个仓库。
6. 第二天早上 9 点后打开“洞察”，就能看到第一次每日分析的结果。也可以在洞察页点“更新分析”马上跑一次。
7. **加同事**（可选）：先在 NocoBase 后台添加用户，再到 设置 → 成员 给他选“成员”或“管理员”。没选角色的人登录后用不了。

## 每天怎么用

1. **看洞察**：顶部提示有没有等你处理的任务；下面左边是“今天的变化”——每日分析找出的变化，AI 逐条给结论（建议处理、建议观察、无需处理），分成待处理、观察中、已处理三组，和机会页的三个标签一样；右边是“当前状况”——不看变化，只看现在的状态（比如审计有几个严重问题、几个帖子没人回），问题不解决会一直在。
2. **处理机会**：在洞察或“机会”页，看依据和建议做法，点“交给 Agent”或“忽略”。交出去时会建好任务并打开任务页，看过任务说明、确认做法后点“确定开始执行”才开始。
3. **在任务里把关**：Agent 写出方案或文档时，你看过再批准，或者写修改意见让它重做。改网站的任务，Agent 会开 PR，你点“看效果并发布”，看改动对比和预览，确认后合并。
4. **看效果**：上线后系统核实页面已经更新，在第 7 天和第 28 天对比改动前后的点击、曝光、排名和访问，结论显示在任务和洞察页。效果不好可以一键开回退 PR。

数据页上看到的东西，比如关键词差距、审计问题、AI 搜索里没提到你的问题，也可以勾选后点右上角“交给 Agent”。

## 页面一览

菜单里的数据页面接入对应数据源后才出现。

| 分组 | 页面 | 看什么 |
| --- | --- | --- |
| 主线 | 洞察、机会、任务 | 每天的结论、值得做的事、所有任务 |
| 网站与产品 | 访问、页面、审计、GitHub、下载量 | 访问来源与页面、全部页面清单、网站问题、Star 与 Issues、npm/PyPI/Docker 下载量 |
| 搜索与市场 | 搜索表现、关键词、竞品、AI 搜索、趋势 | Google 搜索点击与排名、已保存的关键词与排名跟踪、和竞品的对比、AI 回答里有没有提到你、搜索热度 |
| 社区 | 论坛、Hacker News、Reddit、X、Discord、Slack | 社区里在讨论什么、有没有没人回的问题 |
| AI 团队 | Agent、做法、Skills、项目知识、分析规则 | 谁来干活、怎么干、按什么规矩；分析规则里能看到并调整 AI 怎么找变化、怎么判断 |
| 设置 | 数据接入、成员 | 接数据、看各数据源的同步状态、看花了多少钱；给同事选角色 |

**管理员和成员**：管理员能改设置（数据接入、AI 团队、分析规则、成员）；成员能看全部页面、交给 Agent、忽略机会，在自己负责的任务里看方案、审核和发布。别人负责的任务，成员能看、能留言。洞察顶部和“任务”菜单的数字只算你负责的任务。

## 哪些会花钱

- **在线 AI**：每日分析和各处的 AI 建议按你选的模型收费，由模型服务商计费。
- **本机 Agent**：用你电脑上 Claude Code 的额度。
- **DataForSEO**：在数据接入里设每月预算，超了就停，花费也在那里看。查询结果不确定时不会自动重试，避免重复收费。常见花费：
  - 关键词建议：一次约 $0.01；
  - 竞品对比：每个竞品每月约 $0.04；
  - 趋势：每周约 $0.022；
  - Reddit：每周约 $0.002；
  - AI 搜索的问题：每个主题每个平台每月约 $0.2；
  - 品牌提及：一次查询约 $0.3–0.4；
  - Lighthouse：一次约 $0.005。

  排名跟踪、趋势、竞品、AI 搜索问题是你开启后自动定期查；其余都是你点了才查。
- **X**：用你自己的 API Token，按 X 的价格收费，可以设每月上限（默认 $5）。

## 数据和安全

- 所有密钥加密存在 NocoBase 里，不会出现在页面、日志和 AI 的提示词里。
- 本机 Agent 只改你登记的仓库，以分支和 PR 的形式提交；发布一定要你确认，而且合并的是你看过的那个版本。
- 网页、论坛帖子、上传的资料只当参考，不会被当成指令执行。
- 数据缺失时显示为空，不当成 0；估算数据会标明是估算。

## 常见问题

- **洞察是空的**：每日分析还没跑过，或者还没接数据。接好数据后点“更新分析”。
- **提示“还没有接入在线 AI”**：去 AI 团队 → Agent 接入。
- **任务一直“等本机 Agent 接手”，或 Agent 页显示电脑离线**：那台电脑上的 Agent 程序停了（运行它的终端窗口关了、电脑重启过）。在 Agent 页点那台电脑的“重新连接”，照着在仓库目录运行 `node apps/agent/dist/cli.js install-service`：装成后台程序，以后关掉终端、重启电脑也会自动运行（目前只支持 Mac；其他电脑运行 `node apps/agent/dist/cli.js start`，窗口别关）。电脑睡眠时也会离线，醒来后自动连上。
- **看本机 Agent 是否在后台运行**：Agent 页电脑那一行显示“后台运行”或“在终端里运行”，后者点“设为后台运行”照着做。也可以在仓库目录运行 `node apps/agent/dist/cli.js status`；日志在 `~/.nocoreach-agent/logs/agent.log`。不想让它在后台运行了：`node apps/agent/dist/cli.js uninstall-service`。
- **页面是旧的**：发布新版本后，打开着的页面会提示“NocoReach 有新版本”，点“刷新”。
