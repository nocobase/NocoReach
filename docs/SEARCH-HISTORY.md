# 搜索表现的历史数据

默认网页搜索的每日点击、曝光和平均排名会长期保存在数据库中。选择近 90 天或近 12 个月时，优先读取同一份每日汇总；切换范围只补缺少的日期。首次补齐不需要获取全年查询词和页面明细。

管理员打开一个缺少历史的范围后，系统会先补当前周期，再补可获取的比较周期。成员可以查看已保存的结果，需要补齐时请管理员打开相同范围。自动补齐最早到当前日期往前 16 个日历月；更早已保存的数据仍保留。报表的结束日期为洛杉矶日期今天减三天，最近的初步数据单独展示。

页面会显示有记录、Google 无记录和尚未获取的天数，以及有记录的日期范围和最后保存时间。没有记录的日期保留空白，不当作零流量；返回了数值为零的有效记录则显示零。记录未齐全时，数字标为已取得数据合计，当前期与比较期都完整后才显示变化。

获取失败不会删除已保存的数据。有限次数的自动重试仍失败后，由管理员点击“重试”；暂停后需要点击“恢复获取”。反复刷新页面不会绕过失败或暂停状态。

定时同步开启时继续更新最近七天。较早历史默认读库；管理员可点击“重新获取所选汇总”重新核对，也可以重查 Google 曾经无记录的日期。关闭定时同步时，页面会提示近期数据不会自动更新。

查询词、页面和细分明细点击后才独立获取并缓存。其他搜索类型及带国家、查询词或页面筛选的报表也按需查询，不会写入默认网页搜索的全站汇总。Google 可能省略匿名查询或限制明细行数，因此明细合计可能与全站汇总不同。

验收时应使用同一项目的精确 Search Console 站点属性、网页搜索、相同起止日期和相同筛选条件，与 Google Search Console 数据核对。点击与曝光按日求和，点击率为总点击除以总曝光，平均排名按曝光加权。两个范围的指标相同可能是合法结果，不能单凭数字是否不同判断修复是否有效。
