# NocoReach

基于 NocoBase 3 的 AI 优先市场分析与行动工作区，帮助市场人员从数据走向推广决策，而不是先学习复杂分析工具。

本仓库当前是**设计与交付记录基线**，尚未包含可运行源码。现有系统仍为本地单项目管理员试运行，不能视为可对外发布的多租户产品。

- [设计决策](docs/DECISIONS.md)：为什么这样设计。
