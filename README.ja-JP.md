## データには多くの機会があるのに、これまでは見つからず、手もつけられなかった

これまで、マーケティングチームは毎日データを書き出して表にまとめ、BI で数字を確認し、人が一件ずつ作業を割り振っていました。手が回るのは、ごく一部の機会だけでした。

NocoReach は毎日すべてのデータを分析し、取り組む価値のあることを根拠とともに見つけます。確認すれば、複数のタスクをまとめてエージェントに任せ、公開後の効果も自動で比較します。

| ステップ                | 内容                                                                          |
| ----------------------- | ----------------------------------------------------------------------------- |
| 1. データを一か所に     | Web サイト、検索、AI検索、コミュニティ、競合を毎日同期                        |
| 2. 毎日の分析           | AI がその日の変化を一件ずつ判断し、取り組む価値のあるものを改善機会にまとめる |
| 3. エージェントに任せる | 確認すれば、複数のタスクが同時に進む                                          |
| 4. あなたがレビュー     | 記事やページの変更は、承認してから公開                                        |
| 5. 効果の比較           | 公開から 7 日後と 28 日後に自動で比較                                         |

## 毎日、取り組む価値のあることを自動で見つける

週次レポートを待つ必要も、十数個の管理画面を見て回る必要もありません。毎日 09:00 に、NocoReach が分析ルールに沿ってすべてのデータの変化を確認し、取り組む価値があるかを AI が一件ずつ判断して、根拠を添えます。

- **ルールが変化を見つける**：44 個の分析ルールを内蔵し、検索、アクセスとコンバージョン、コンテンツ、コミュニティ、製品への関心と利用、競合をカバーします。ルールは「検索クリックが 20% 以上下がったら知らせて」のように、一文で調整できます。
- **AI が取り組む価値を判断する**：プロジェクトナレッジを踏まえて一件ずつ判断し、結論は「対応推奨」「経過観察」「対応不要」の 3 つ。理由と根拠も記載します。
- **改善機会にまとめる**：対応推奨の変化は改善機会になり、エージェントに任せるか無視するかを選べます。経過観察の変化には判断の条件と期限を書き、期限が来たら改めて判断します。新しい発見がない日は、無理に提案を作りません。

## すべての改善機会に、根拠がある

![改善機会：何が起きたか、なぜ取り組むべきか、どうするか](https://cdn.jsdelivr.net/gh/nocobase/NocoReach@main/docs/images/readme/opportunities-en.webp)

- **何が起きたか**：ページ、指標、変化の幅、データの出どころまで具体的に示します。
- **なぜ取り組むべきか**：プロジェクトナレッジを踏まえて影響を説明し、優先度と工数を示します。
- **判断がつかないものは、まず観察**：判断の条件と期限を書き、期限が来たら結論を出します。改善機会になるか、対応不要になるかのどちらかです。

## 確認したら、エージェントが実行する

仕事の種類ごとにプレイブックがあり、エージェントが何ステップで進めるか、どこであなたが確認するかが決まっています。12 個のプレイブックを内蔵し、調査・分析、コンテンツ作成、コンテンツ改善、サイトの技術対応をカバーします。内蔵のプレイブックはそのまま調整でき、一文で説明すれば AI が新しいプレイブックを下書きします。

| 種類             | 内蔵プレイブック                                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 調査・分析       | 変化の原因調査、競合比較、キーワード調査、コミュニティの質問のまとめ                                                             |
| コンテンツ作成   | コミュニティへの返信の下書きを作成、コンテンツのテーマと構成案、ドキュメントページを作成、ブログ記事を作成、リリースノートを作成 |
| コンテンツ改善   | 既存ページを改善、他の言語に翻訳                                                                                                 |
| サイトの技術対応 | 技術的な修正                                                                                                                     |

複数のタスクが同時に進みます。タスクはエージェントごとに見られ、それぞれが今何をしていて、次に何をし、どれがあなたを待っているかが一目でわかります。タスクは毎日の分析から生まれるもの（Found by AI）のほか、自分で作ることもできます。

## すべての変更は、あなたがレビューする

エージェントはプレイブックに沿って作業を終えると、あなたを待ちます。記事は読者が見るとおりにプレビューでき、ページの変更は変更前後を表示します。問題なければ承認して公開し、直したい点があれば修正依頼を出してエージェントに直させるか、自分で直接編集します。

![レビュー：記事のプレビュー、承認して公開、修正依頼](https://cdn.jsdelivr.net/gh/nocobase/NocoReach@main/docs/images/readme/review-en.webp)

- **コミュニティへの返信**：エージェントがドキュメントを読み、返信のない投稿ごとに返信を下書きします。元の投稿に貼り付けて送るのはあなたで、NocoReach が代わりに投稿することはありません。
- **修正依頼**：直してほしい点を書くと、エージェントが新しい版を作り、もう一度あなたのレビューに回します。

## 公開後の効果は、自動で比較する

変更の公開から 7 日後と 28 日後に、変更したページの検索クリック数とページビューを、公開前の同じ日数と自動で比較します。結論は「上昇」「低下」「明確な変化なし」「データ不足」のいずれかで、データの動きだけを示し、因果関係は推定しません。

## すべてのデータを、一か所に

22 のデータソースに対応し、同じ場所に保存して、毎日の分析でまとめて見ます。データの種類ごとに詳細ページもあり、そこで見つけた取り組むべきことも、そのままエージェントに任せられます。

| 分類                         | データソース                                             |
| ---------------------------- | -------------------------------------------------------- |
| Web 解析                     | GA4                                                      |
| 検索                         | Search Console、キーワードと順位、Google Trends          |
| AI検索                       | ChatGPT、Google AI Overviews                             |
| Web サイトとドキュメント     | Web サイトのコンテンツ、サイト監査                       |
| オープンソースとダウンロード | GitHub リポジトリ、GitHub Traffic、npm、PyPI、Docker Hub |
| コミュニティ                 | Discourse、Discord、Slack、GitHub Discussions            |
| SNS と動画                   | X、Reddit、Hacker News、YouTube、Bilibili、小紅書        |
| 競合                         | 競合のサイト、競合の GitHub、競合の順位キーワード        |
| 変更と公開                   | Web サイトのソース（Git リポジトリ）、ブログ CMS         |

必要なデータソースがまだない場合も、NocoReach はオープンソースなので、Coding Agent に必要に応じて開発させられます。接続すれば、ほかのデータと同じように毎日の分析に入ります。

<p align="center">
  <img src="https://cdn.jsdelivr.net/gh/nocobase/NocoReach@main/docs/images/readme/connect-en.webp" width="600" alt="データソース：パソコン上のエージェントにまとめて接続させる">
</p>

- **エージェントにまとめて接続させる**：一つずつ接続する必要はありません。手順をパソコン上の Claude Code や Codex にコピーすると、Web サイトとリポジトリを調べて接続計画を出し、確認すればまとめて接続します。認証やトークンの入力は、引き続きブラウザ上であなたが行います。
- **結論の前に、データを確認する**：データの健全性では、同期に失敗したもの、データが古くなったもの、再認証が必要なものを一覧にし、それぞれの対処を示します。同期に失敗したときは、毎日の分析がどのデータを欠いた結論かを明記します。
- **コストの上限**：DataForSEO など従量課金のデータソースには月の予算を設定でき、上限に達すると止まります。

取り組むべきことを見つけたら、その場でエージェントに任せることもできます。たとえば AI検索では、ChatGPT と Google AI Overviews があなたの分野の質問にどう答え、どのブランドに言及し、どのサイトを引用しているかを追跡します。ほかのブランドは出てくるのにあなたは出てこない質問を選び、そのままエージェントに任せます。

## あなたのやり方で動く

- **ナレッジ**：ブランド、製品、読者、トーン、避けるべき内容をメモリーに書いておくと、毎回の実行で読み込まれます。長い資料はナレッジベースに入れ、必要なときに検索します。レビューで出した修正依頼は更新の提案になり、確認するとメモリーに書き込まれます。
- **スキル**：スキルは、ある種類の仕事の進め方を書いたもので、Claude Code などのツールでも使える標準的な SKILL.md 形式です。必要なマーケティングのスキルは、GitHub のリンクを貼るだけでインポートできます。
- **モデルとエージェント**：毎日の分析は、設定したクラウドのモデルで動きます。タスクを実行する Claude Code や Codex は、あなたのパソコンやサーバー上で動きます。モデルもエージェントも自由に選べ、使用量はいつでも確認できます。

| NocoReach が担当                                                             | あなたが決める                         |
| ---------------------------------------------------------------------------- | -------------------------------------- |
| 毎日データを分析し、根拠のある改善機会を提案する                             | どの改善機会に取り組み、誰が担当するか |
| キーワード、競合、コミュニティでよく出る質問を調べる                         | ブランド、トーン、変えてはいけない内容 |
| ページを修正し、ドキュメントや記事を書き、返信を下書きし、技術的な問題を直す | 変更をレビューし、公開するかを決める   |
| 公開から 7 日後と 28 日後に効果を比較する                                    |                                        |

## NocoBase Core で構築

NocoReach は [NocoBase Core](https://www.nocobase.com) で構築されており、オープンソースで無料です。新しい機能が必要なら、Coding Agent に自分の業務に合わせてカスタマイズさせられます。カスタマイズするのは業務の部分だけで、基盤は NocoBase が継続的に保守・アップグレードします。

- **オープンソースで無料**：ソースコードはすべてこのリポジトリにあります。
- **プライベートデプロイ**：自分のサーバーで運用し、コードとデータはあなたのものです。サーバーのネットワークから外部サービスに直接アクセスできない場合は、「設定 › ネットワーク」でプロキシを設定できます。
- **モデルとエージェントを自由に選べる**：特定のベンダーに縛られず、Claude Code、Codex などのコーディングツールと各種の大規模言語モデルに対応します。
- 画面は日本語を含む 10 言語に対応し、1 つのインスタンスで複数のプロジェクトを管理できます。

## はじめに

まず見てみたい場合は、[オンラインで試す](https://solutions.nocobase.com/reach/)ことができます。デモアカウントで自動的にサインインし、データはすべて架空なので、自由に操作できます。

自分のパソコンで動かすには、Node.js 24 と pnpm が必要です。

```bash
git clone https://github.com/nocobase/nocoreach.git
cd nocoreach
pnpm install
pnpm nocobase config init
pnpm dev
```

ターミナルに表示されたアドレスを開き、`config.yml` の初期管理者アカウントでサインインします（本番で使う前にパスワードを変更してください）。続いて：

1. プロジェクトを作成し、Web サイトのアドレスを入力します。
2. 「設定 › データソース」でデータを接続します。手順をパソコン上の Claude Code や Codex にコピーして、まとめて接続させることもできます。
3. 「AIチーム › エージェント」で毎日の分析に使うモデルを設定し、タスクを実行するエージェントを接続します。
4. 「インサイト」で毎日の分析結果を確認します。

実際のアカウントなしで試すには、[模擬データ](docs/MOCK-DATA.md)でローカルにデモ環境を起動できます。本番環境へのデプロイは[ビルドとデプロイ](docs/APP-TEMPLATE.md)を参照してください。
