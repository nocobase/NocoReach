## 数据里有很多机会，以前大多没被发现，也没人去做

以前，市场团队每天导出数据做表，放进 BI 看结果，再由人一项项安排执行，能顾上的只是少数。

现在，NocoReach 每天分析全部数据，找出值得做的事并写明依据；你确认后，多项任务同时交给 Agent 执行，上线后自动对比效果。

| 步骤            | 做什么                                    |
| --------------- | ----------------------------------------- |
| 1. 数据汇在一处 | 网站、搜索、AI 搜索、社区和竞品，每天同步 |
| 2. 每日分析     | AI 逐条判断当天的变化，把值得做的写成机会 |
| 3. 交给 Agent   | 你确认后，多项任务同时推进                |
| 4. 由你审核     | 文章和页面改动，通过后才发布              |
| 5. 效果对比     | 上线后第 7、28 天自动对比                 |

## 每天，自动找出值得做的事

不用等周报，也不用翻十几个后台。每天 09:00，NocoReach 按分析规则检查所有数据的变化，由 AI 逐条判断是否值得做，并写明依据。

- **规则找出变化**：内置 44 条分析规则，覆盖搜索、访问与转化、内容、社区、产品关注与使用和竞品。规则可以用一句话调整，比如“搜索点击下降超过 20% 就提醒我”。
- **AI 判断值不值得做**：结合项目知识逐条判断，结论分三种：建议处理、建议观察、无需处理，并写明理由和依据。
- **写成机会**：建议处理的写成机会，等你交给 Agent 或忽略；建议观察的写明判断条件和截止日期，到期再判断。没有新发现时，不凑数。

## 每个机会，都写明依据

![机会：发生了什么、为什么值得做、建议怎么做](https://cdn.jsdelivr.net/gh/nocobase/NocoReach@main/docs/images/readme/opportunities-zh.webp)

- **发生了什么**：具体到页面、指标、变化幅度和数据来源。
- **为什么值得做**：结合项目知识说明影响，标出优先级和投入。
- **拿不准的，先观察**：写明判断条件和截止日期，到期给出结论：变成机会，或者无需处理。

## 确认后，交给 Agent 执行

每类工作都有对应的做法，写明 Agent 分几步做、你在哪一步把关。内置 12 种做法，覆盖调研分析、内容创作、内容优化和网站技术；内置做法可以直接调整，也可以用一句话让 AI 起草新的做法。

| 类型     | 内置做法                                                         |
| -------- | ---------------------------------------------------------------- |
| 调研分析 | 变化原因调研、竞品对比、关键词调研、社区问题汇总                 |
| 内容创作 | 起草社区回复、内容选题与大纲、新建文档页、写博客文章、写发布说明 |
| 内容优化 | 优化现有页面、翻译成其他语言                                     |
| 网站技术 | 技术修复                                                         |

多项任务同时推进。按 Agent 看任务：每个 Agent 正在做什么、接下来做什么、哪些在等你，一眼看清。任务来自每日分析（Found by AI），也可以由你新建。

## 每项改动，由你审核

Agent 按做法完成后停下来等你：文章按读者看到的样子预览，页面修改显示改动前后。满意就通过并发布；不满意就提修改意见，Agent 按意见调整，也可以直接编辑。

![审核：文章预览、通过并发布、提修改意见](https://cdn.jsdelivr.net/gh/nocobase/NocoReach@main/docs/images/readme/review-zh.webp)

- **社区回复**：Agent 读过文档，给没人回复的帖子逐条起草回复；你复制到原帖发出，NocoReach 不会替你发帖。
- **提出修改意见**：不满意就写下要改什么，Agent 按意见改出新的一版，再交给你审核。

## 上线之后，效果自动对比

改动上线后第 7 天和第 28 天，自动对比改过的页面在上线前后同样天数的搜索点击和浏览量。结论分为上升、下降、无明显变化和数据不足，只描述数据变化，不推断因果。

## 所有数据，汇在一处

已支持 22 个来源，统一存储，每日分析放在一起看。每类数据也有详细页面，看到值得做的，可以直接交给 Agent。

| 类别           | 数据来源                                           |
| -------------- | -------------------------------------------------- |
| 网站分析       | GA4                                                |
| 搜索           | Search Console、关键词与排名、Google Trends        |
| AI 搜索        | ChatGPT、Google AI 概览                            |
| 网站与文档     | 网站内容、网站审计                                 |
| 开源项目与下载 | GitHub 仓库、GitHub Traffic、npm、PyPI、Docker Hub |
| 社区           | Discourse、Discord、Slack、GitHub Discussions      |
| 社交与内容平台 | X、Reddit、Hacker News、YouTube、B 站、小红书      |
| 竞品           | 竞品官网、竞品 GitHub、竞品排名关键词              |
| 修改与发布     | 网站源码（Git 仓库）、博客 CMS                     |

需要的来源还没有？NocoReach 开源，可以让 Coding Agent 按你的需求开发新的数据源，接入后同样进入每日分析。

<p align="center">
  <img src="https://cdn.jsdelivr.net/gh/nocobase/NocoReach@main/docs/images/readme/connect-zh.webp" width="600" alt="数据接入：交给电脑上的 Agent 一次接好">
</p>

- **交给 Agent，一次接好**：不用一个个接入。把指引复制给你电脑上的 Claude Code 或 Codex，它会调研你的网站和仓库，列出接入计划，你确认后一次接好。授权和 token 仍由你在浏览器里填写。
- **先看数据，再看结论**：数据健康列出同步失败、数据过期和需要重新授权的来源，每个都给出对应操作。同步失败时，每日分析会注明结论缺少哪些数据。
- **费用可控**：DataForSEO 等按量计费的查询可以设每月预算，达到即停止。

看到值得做的，也能直接交给 Agent。比如 AI 搜索：追踪 ChatGPT 和 Google AI 概览怎么回答你所在领域的问题，提到了谁、引用了哪些网站。勾选别人出现、你没有的问题，直接交给 Agent。

## 按你的方式工作

- **项目知识**：品牌、产品、受众、语气和禁区写进记忆，每次执行都会读取；长篇资料放进知识库，需要时检索。你审核时提的修改意见，会变成更新建议，确认后写进记忆。
- **Skills**：Skill 写清某类事情怎么做，格式是通用的 SKILL.md，Claude Code 等工具都能用。需要的市场技能，贴一个 GitHub 链接就能导入。
- **模型与 Agent**：每日分析用你配置的云端模型；执行任务的 Claude Code、Codex 运行在你的电脑或服务器上。模型和 Agent 自由选择，用量随时可查。

| NocoReach 负责                                       | 你来决定                 |
| ---------------------------------------------------- | ------------------------ |
| 每天分析数据，提出有依据的机会                       | 做哪些机会、由谁负责     |
| 调研关键词、竞品和社区高频问题                       | 品牌、语气和不能改的内容 |
| 修改页面、撰写文档和文章、起草社区回复、修复技术问题 | 审核改动，决定是否发布   |
| 上线后第 7、28 天对比效果                            |                          |

## 基于 NocoBase Core

NocoReach 基于 [NocoBase Core](https://www.nocobase.com) 构建，开源免费。需要新功能，可以让 Coding Agent 按自己的业务需求定制；定制只改业务部分，底座由 NocoBase 持续维护和升级。

- **开源免费**：完整源码都在这个仓库中。
- **私有部署**：部署在你自己的服务器上，代码和数据归你所有。服务器所在网络不能直接访问外部服务时，可以在“设置 › 网络”配置代理。
- **模型与 Agent 自由选择**：不绑定厂商，支持 Claude Code、Codex 等编码工具和各类大模型。
- 界面支持 10 种语言，一个实例可以管理多个项目。

## 快速开始

只想先看看？[在线体验](https://solutions-cn.nocobase.com/reach/)已用演示账号自动登录，数据都是虚构的，可以随意操作。

在自己的电脑上运行，需要 Node.js 24 和 pnpm：

```bash
git clone https://github.com/nocobase/nocoreach.git
cd nocoreach
pnpm install
pnpm nocobase config init
pnpm dev
```

打开终端中显示的地址，使用 `config.yml` 中的初始管理员账号登录（正式使用前请修改密码），然后：

1. 新建项目，填写官网地址；
2. 在“设置 › 数据接入”中接入数据，也可以把指引复制给你电脑上的 Claude Code 或 Codex，一次接好；
3. 在“AI 团队 › Agent”中配置每日分析用的模型，并连接执行任务的 Agent；
4. 在“洞察”中查看每日分析结果。

不想接真实账号，可以用[模拟数据](docs/MOCK-DATA.md)在本地启动演示环境。生产部署请参考[构建与部署](docs/APP-TEMPLATE.md)。
